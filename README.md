# Vuln-Lab
An intentionally vulnerable web application for learning, practicing, and documenting web application security.

## 🎯 About

VulnLab is a deliberately vulnerable web application designed as a hands-on environment for understanding common web security vulnerabilities.

The project focuses on learning how vulnerabilities work at the code level, how they can be discovered and exploited during authorized security testing, and how they can be properly remediated.

## 🧠 Planned Vulnerabilities

- SQL Injection
- Reflected XSS
- Stored XSS
- IDOR
- Path Traversal
- Unrestricted File Upload
- Broken Access Control
- Authentication & Session vulnerabilities
- API security vulnerabilities
- Information Disclosure

## 🛠️ Planned Tech Stack

- Python
- Flask
- SQLite
- HTML / CSS / JavaScript
- Bootstrap
- REST APIs
- Docker

## 🔍 Security Tools

The application will be tested using tools such as:

- Burp Suite
- Nmap
- FFUF
- Nuclei
- SQLMap

## 🚧 Project Status

🟡 **In Development**

The project is currently in the planning and learning phase.

## 🎯 Goals

- Understand common web application vulnerabilities
- Learn secure and insecure coding practices
- Practice manual web application penetration testing
- Document vulnerability discovery and exploitation
- Implement and compare security remediations
- Build a realistic cybersecurity portfolio project

## ⚠️ Disclaimer

VulnLab is intentionally vulnerable and is designed for educational purposes only.

Run and test the application only in an environment you own or have explicit authorization to test.
